# Meeting brief — how to use

## Open for the meeting

1. **Word (best for sharing / Fiverr / client):**  
   `docs/DMHR_Meeting_Brief.docx`  
   — same text + all diagram images embedded.
2. **Best for presenting / PDF:** open  
   `docs/DMHR_Meeting_Brief.html`  
   in Chrome or Edge → **Ctrl+P** → Save as PDF.
3. **Markdown with images:** open  
   `docs/DMHR_Meeting_Brief.md`  
   in Cursor / VS Code / GitHub preview.
4. **Diagram images only:** folder  
   `docs/diagrams/*.png`  
   (also `.svg` versions).

To rebuild the Word file after diagram changes:  
`python docs/build_meeting_brief_docx.py`

## What’s inside

- Portal explanation (simple language)
- Actors, two sides, goals
- All foundation diagrams (use cases, context, journeys, sitemap, ER)
- Foundation checklist + out of scope
