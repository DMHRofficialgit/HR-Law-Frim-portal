## Already decided (for your info — no reply needed)

- **E-signature:** In-portal only (I agree + typed name + signature PNG / draw + timestamp + IP). Statuses: Sent → Awaiting Signature → Signed/Returned → Reviewed. No third-party e-sign. No wet ink.
- **Payments / Direct Debit:** Admin pastes Direct Debit and initial payment links manually.
- **Users:** One login per client company. Both email invite and temporary passwords.
- **Onboarding:** Portal usable as soon as Admin adds the company. **Admin only** marks Complete. **Six-stage journey**. Pack files land in client **My Onboarding** (Firm Library → transfer). Sign via Signatures. Six ongoing folders separate.
- **UX:** Copy HTML prototype user-flow structure; Apple-like look. E-sign = real Part 4.1 (not in mock).
- **Email:** Microsoft 365–ready via **SMTP Settings** in the portal (address, password, host, etc.).
- **Files / folders:** Configurable types/size (Word + PDF min). Six operational folders + **My Onboarding** for the one-time pack. Unlimited storage. Keep versions; keep until removed.
- **Private Space:** One Admin — sees all client Private Space. Admin-only private notes stay Admin-only.
- **Cases:** Statuses and categories as agreed (+ custom categories in Settings). Client can reply after submit; Admin can request a client response. Notify Admin ↔ Client both ways.
- **Employees:** Profiles in phase 1 (both Admin and Client can edit). No employee self-login portal.
- **Branding / UI:** Logo from dmhrgroup.com. Clean modern Apple-like UI (not old mockup). Hosting UK-friendly.
