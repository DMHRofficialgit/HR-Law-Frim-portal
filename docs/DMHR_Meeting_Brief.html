1. What is this portal?

DM.HR Group helps care companies with HR and employment issues.

Today that work is messy (email, Dropbox, paperwork). This portal is one private website where:

  • DM.HR manages their clients
  • Each client company only sees their own stuff
  • Documents live in clear folders
  • Problems become cases you can track
  • New clients get guided online onboarding
  • Old clients skip that and just use the portal

Think: shared office online between DM.HR and each company — not a public website.

2. Actors (who uses it)

ActorWhoSimple job
Admin / HR team People at DM.HR Add clients, upload docs, run onboarding, handle cases
Client user Person at the care company (manager / contact) Login, get docs, open cases, upload private files
(later) Employee Staff of the care company Not a main login in foundation — employees are mostly records

For v1 foundation: 2 real sides — Admin and Client.

4. What we are achieving

  1. Each company has its own locked room (no peeking at other companies).
  2. Docs are organised (not lost in email).
  3. Cases have a clear thread (open → update → close).
  4. New clients can onboard online; old ones jump straight in.
  5. DM.HR looks professional and organised.

One line: Admin = control room for all clients. Client = that company’s private folder + cases. Goal = stop chasing HR work in email.

7. User workflows / journeys

A) Existing client

  1. Admin creates/imports company + login
  2. Marks them Already onboarded
  3. Client logs in → dashboard (no onboarding)
  4. Uses docs + cases + private space
flowchart TD
  A[Admin creates or imports client] --> B[Mark Already Onboarded]
  B --> C[Send invite / login details]
  C --> D[Client signs in]
  D --> E[Dashboard - skip onboarding]
  E --> F[Docs / Cases / Private Space]

B) New client

  1. Admin adds company
  2. Send Terms → client signs online
  3. Send welcome pack
  4. Issue compliance docs
  5. Send Direct Debit + first payment links
  6. Admin marks onboarding complete
  7. Client uses normal portal
flowchart TD
  A[Admin adds new client] --> B[Send Terms of Business]
  B --> C[Client signs and returns online]
  C --> D[Send welcome pack]
  D --> E[Issue compliance documents]
  E --> F[Send DD link + initial payment link]
  F --> G[Admin confirms onboarding complete]
  G --> H[Client uses normal dashboard]

C) Documents

  1. Admin opens Client X → picks folder
  2. Uploads file
  3. Client opens same folder → downloads
  4. Private Space: client can also upload; admin can access
flowchart TD
  A[Admin opens Client X] --> B[Pick document area]
  B --> C[Upload file]
  C --> D[File stored against that organisation]
  D --> E[Client opens same area]
  E --> F[View / download]
  G[Client opens Private Space] --> H[Upload own file]
  H --> I[Admin can also access Private Space]

D) Case

  1. Client: Add a case (+ optional attachment)
  2. DM.HR reviews / replies / updates status
  3. Client: Check a case → client-visible updates
  4. Email notifies on important updates
  5. Internal HR notes stay hidden from client
flowchart TD
  A[Client: Add a case + optional attachment] --> B[Case saved to organisation]
  B --> C[Appears in Admin case list]
  C --> D[Admin updates status / asks for info]
  D --> E{Update type?}
  E -->|Client visible| F[Client sees it + optional email]
  E -->|Internal note| G[Admin only - never emailed to client]
  F --> H[Client: Check a case]
  G --> C
  H --> I[Received / Pending / Closed]
